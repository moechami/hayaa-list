# The build checks every domain in the pinned top-sites list (Tranco, top
# 10,000; see CREDITS.md). Each one the list would block must be named here.
# An unreviewed one stays listed if the previous release listed it; a new one
# is held back (left out of the release, written to dist/held-back.txt and
# listed in an issue) until reviewed. A person then reviews each candidate:
#   - a genuinely adult site is added here;
#   - a wrong entry goes to data/allowlist.txt instead, with a reason.
#
# What counts as adult: sites whose main content is sexual (video, images,
# stories, comics, games, live cams, escort and hook-up listings, explicit
# forums), and the advertising, CDN and mirror domains that serve them.
# General sites where explicit material is a small or opt-in corner (news,
# shops, mainstream dating, general manga readers, general art and creator
# platforms) are not, and are allowlisted.
#
# Judgement calls in this review (2026-10-30; the borderline ones confirmed
# by the maintainer the same day), kept here and open to reports:
#   4chan.org            kept: explicit boards are a large, unfiltered part

#                        boards that show explicit images by default
#   romeo.com, grindr.com, sniffies.com, adam4adam.com  kept: hook-up
#                        services; general dating sites are allowlisted
#   ome.tv, videochatmix.com  kept: random video chat, in the cam and chat
#                        category
#   janitorai.com, crushon.ai, spicychat.ai, polybuzz.ai, emochi.com  kept:
#                        explicit role-play chat is their main use
#   seaart.ai, pixai.art kept: image sites dominated by explicit images
#   fantia.jp, dlsite.com, toomics.com  kept: mostly adult (R18) catalogues
#   questionablequesting.com  kept: the forum exists for explicit fiction
#   Allowed instead (data/allowlist.txt): character.ai, furaffinity.net,
#   boosty.to, tango.me, fc2.com (root only; video.fc2.com stays listed),
#   mangago.me, manhwaweb.com. forogore.net is gore, not sexual, so it is out
#   of scope and allowlisted.
#   Domains with no public page (ad, CDN and redirect hosts) were kept when a
