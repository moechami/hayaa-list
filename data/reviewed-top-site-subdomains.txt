# The build checks every listed host whose registrable domain is in the top
# 1,000 of the pinned top-sites list (Tranco; see CREDITS.md), such as
# m.vk.com under vk.com. The site itself stays reachable, but one wrong entry
# here would still break it for many people. Each such host must be covered
# by a line here, or the build holds it back (leaves it out of the release
# and opens an issue). A host the previous release already listed stays
# listed while it waits.
#
# Two forms:
#   sub.example.com    this host was reviewed and is adult
#   *.example.com      every listed subdomain of example.com is accepted:
#                      used only for platforms where each subdomain is a
#                      separate person's site (blogs, creator pages, CDN
#                      customer zones), so a wrong entry blocks one small
#                      site, never the platform. Each was sampled by hand.
#
# Wrong entries go to data/allowlist.txt (the host only) with a reason.
