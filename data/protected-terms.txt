# A listed host whose name contains one of these is REMOVED from the list,
# unless data/reviewed-protected.txt names it with a reason: a person looked
# at it and found it genuinely adult. Blocking a recovery or religious site
# is worse than missing an adult one, because the app's users cannot
# override the Blocker. The name is every label except the public suffix
# ("quran.example.co.uk" → quran, example), and hyphens inside a label are
# ignored ("quit-porn" reads as "quitporn").
#
# Forms:
#   contains <term>                  some label contains the term
#   label <term>                     some label is exactly the term
#   contains <term> with <a> <b>...  the name contains the term AND one of the others
#
# Lowercase letters and digits only. A longer word that contains a term is
# covered by it ("addict" covers "addiction", "counsel" covers "counseling"
# and "counsellor", "muslim" covers "muslimah", "islam" covers "islamic").
