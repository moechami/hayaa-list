# Ordinary names: hosts whose names read as an ordinary business, school,
# sport, gambling or other non-adult site.
#
# Every source lists some ordinary sites: expired domains, sites that once
# carried an adult advert, and names some list caught by mistake. A random
# sample of the final list read by name found about 5% of them (a golf
# academy, a Turkish newspaper, a sanitary-ware maker, software houses,
# casinos). The app's users cannot override the Blocker, so a host is
# REMOVED when
#   - its name (every label except the public suffix) matches an
#     "ordinary" pattern, and
#   - nothing in the whole host matches an "adult" pattern.
# The adult list is deliberately broad (it includes "hot", "girl", "video",
# "chat", "club", "18"): one adult-looking word anywhere keeps the host
# listed, so a name like "schoolsletjes" or "casinogirls" stays. Gambling
# names are ordinary here: the list blocks adult sites, not gambling.
#
# Hosts a person reviewed as adult are never removed by this rule: entries
# of data/additions.txt, data/reviewed-top-hits.txt,
# data/reviewed-top-site-subdomains.txt and data/reviewed-protected.txt.
#
# Forms (JavaScript regular expressions, lowercase, no spaces or "#"):
#   ordinary <pattern>
#   adult <pattern>
#
# Reviewed 2026-10-30: samples of the removed hosts were read by name (see
# the commit message for the counts).
