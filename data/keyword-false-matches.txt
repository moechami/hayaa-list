# False keyword matches.
#
# The Block List Project (now frozen) built its porn list partly by matching
# words such as "sex" inside domain names, which also caught Essex, Sussex,
# the surname Sexton and "homes exteriors". These rules apply ONLY to hosts
# that no other source lists (config.ts, KEYWORD_MATCHED_SOURCES): a host
# another source lists was put there by a person or a different method and
# is left alone.
#
# A host is removed when
#   - it is named on a "host" line, or
#   - it contains at least one "benign" word, and every "sexual" token in
#     it STARTS inside a benign or "safe" word. The tokens are found at
#     every position, so one that overlaps another is not missed.
# So "essexroofing.co.uk" and "sussextiles.co.uk" (the "sext" starts inside
# "sussex") are removed, but "essexescorts.co.uk" ("escort" outside the
# benign word) and "essexy.com" (not a benign word) stay. A token that
# starts in the last one or two letters of a word and runs past its end
# ("camp" + "pussy") is not counted as inside it: at least min(3, its
# length) of its letters must lie inside the word.
#
# Forms (patterns are JavaScript regular expressions, matched against the
# whole lowercase host; no spaces, no "#"):
#   benign <pattern>   a non-sexual word that contains a sexual-looking substring
#   safe <pattern>     an ordinary word that hides a short token ("photo"
#                      hides "hot", "camp" hides "cam", "assist" hides
#                      "ass", "title" hides "tit"); it never makes a host
#                      removable on its own, so "petites-salopes.com" stays
#   sexual <pattern>   a sexual-looking substring; the list is deliberately
#                      generous (it includes "hot", "cam", "girl"), because
#                      a pattern here only ever keeps an entry listed
#   host <host>        one host, with the reason in the comment
#
# Reviewed 2026-10-30: the removed hosts were sampled by hand, judged by
# name only (see the commit message for the counts).

# --- Benign words ---
# Essex only as a county: at the start, after "-" or ".", or after a place
# word. "...es" + "sex" ("likessex", "couplessex") is never read as Essex.
benign (?:^|[-.]|north|south|east|west|mid|new|the|of|in|for|and|herts|suffolk|kent|london|windsor)essex(?![eioy])  # English county
benign sussex                  # English county ("westsussexestateagents")
benign wessex                  # English region ("wessexutilities")
benign middlesex               # English county ("middlesexurology")
benign sexton(?!ight)          # surname and church office; not "sex tonight"
benign sexterior               # "...s exterior" (homes exteriors, brothers exteriors)
benign (?:business|access|glass|class|cross|compass|brass|grass|process|success|fitness|wellness|wireless|address)-?ex(?![eioy])  # "business express", "access exchange", "glass expert"
benign gasexchange             # gas exchange
# A word ending in "s" followed by an ordinary "ex-" word: "twistedpretzels
# express", "the news explainer", "two chairs exchange". Only after a letter
# (a name starting "sexpert" is left alone), and not where the "ex-" word is
# itself sexual ("exhibitionist", "exposed", "explicit", "extreme"). The word
# covers only the "sex", so a token after it ("phonesextranny") is not hidden.
benign (?<=[a-z])sex(?=press|pert|plor|plain|peri|pedi|po(?!s)|port|cel|chang|clusiv|pan|hibit(?!ionis)|ecut|am|tern|tend|tens|tra|cava|curs|cus|empt|empl|ercis|it(?![eya])|pens|pect|ceed|haust|termin|plos|preso)
benign unisex                  # unisex salons and clothing
benign sextant                 # navigation instrument
benign s?lutheran              # "gs lutheran": the "slut" is in "s" + "lutheran"
benign (?<=[a-z0-9])sex(?=tou(?!r))  # Brazilian "sextou" ("it's Friday"), betting-site names; not "sextour"
benign adslaanbieders          # Dutch: ADSL providers
benign gayrimenkul             # Turkish: real estate (emlak gayrimenkul)
